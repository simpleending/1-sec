## Implemented security fixes

| Boundary | Change and regression evidence |
| --- | --- |
| Local event bus | Embedded NATS requires a random persistent per-instance token. Its directory and credential file are private. Normal collectors discover the file, and the Rust child receives credentials through its inherited environment rather than command arguments. A restart preserves collector credentials. Tests reject absent/wrong credentials and verify authenticated JetStream publication and restart reconnection. |
| Monitoring credentials | Enforcement API responses use detached JSON copies and redact secret fields, configured secrets and full HTTP(S) URLs, including mixed-case schemes and URLs inside errors/history. Policies and dead-letter retry credentials remain intact. Read-key and JSON-field-name regressions cover this boundary. |
| PDF availability | Tokenization advances on unmatched delimiters and dictionary markers. Regressions continue inspecting hidden text after malformed lines; a fuzz target covers parser progress. |
| EXIF availability | IFD traversal has a shared 4,096-entry work budget and remembers the shallowest visited depth. Cycles stop, while a later shallower route can still inspect hidden descendants. Both cases have regressions. |
| Webhook destinations | Retry delivery, direct enforcement, approval notifications and ordinary alert webhooks use the same public-destination transport. It rejects redirects and nonpublic/private/link-local/CGNAT addresses, validates all DNS answers, then dials the validated numeric address. TLS still verifies the original hostname. It does not inherit proxy settings that bypass this policy. Tests cover the actual dispatcher and DNS/dial boundary; legitimate delivery/retry tests use an explicit test-only client. |
| Local retained data | Archive directories and files, imported profiles, and config writers use private permissions. Existing owned archive files and overwritten config files are repaired. Windows uses a protected owner/SYSTEM DACL, rather than relying on ineffective Unix mode bits. ACL readback and ordinary owner access are tested on Windows. Explicitly shared raw archive/config access must be reconsidered when upgrading. |
| TCP syslog | Active connections are capped (default 128). Each complete line must arrive within the read deadline (default 30 seconds); idle/trickling peers expire and shutdown closes peers. Operators can configure both limits. Network admission/TLS remains the deployment's responsibility. |
| External AI privacy | Both AI stages send only canonical event type/category, severity and minute-rounded timestamp. Raw bytes, arbitrary details, summaries, source addresses and identifiers stay local. Unknown type labels become unknown. Keys use a request header and responses are capped at 1 MiB. Mocked outbound-request tests exercise both stages and prove the source event is unchanged. AI receives less diagnostic context; it is not a substitute for local detection or human review. |
| Correlation under sustained attacks | Observations expire individually; retention is capped at 1,024 sources and 32 recent alerts per source. Module counts are rebuilt after pruning. Chain-notification deduplication is retained separately. Oldest evidence is evicted under pressure, which can reduce detection coverage during bursts. |
| Escalation | Re-notifications cannot become new escalation roots, final roots are removed, and short IDs are safe. Re-notifications may log/notify but cannot repeat destructive enforcement actions. Production-style pipeline regression covers re-notify. |
| Password spraying | Per-IP username sets are built in one pass; the detector retains at most 10,000 recent attempts. Distributed and single-IP detections still work. This bounds per-event work; it is not an unlimited-load guarantee. |
| Executable updates | CLI update checks announce available releases and never replace executable code. The maintained installer verifies signed checksum bundles. The legacy skill setup script delegates to that repository-local installer, removing predictable shared temporary downloads. Shell syntax and no-download CLI checks pass. |

## Detection and activation reliability

- Rust workers=0 now selects at least one worker; zero buffer size cannot create an empty consumer batch.
- Merely routing a Go event no longer suppresses independent Rust detections. Duplicate sidecar results are still deduplicated. Source IP and selected principal identifiers travel with match results to correlation and IP-response policies; process-killing authority is not inferred from pattern matches. Go and Rust may both report an event; response cooldowns remain important.
- Optional packet capture publishes the canonical network event format, with addresses and anomaly details. A shared Rust/Go fixture reaches a real Network Guardian alert. IPv6 formatting is corrected and WebSocket flow state is capped at 4,096 entries. These are observed-packet heuristics, not a complete TCP reassembler or proof of a successful WebSocket handshake.
- Service-account learning uses a separate 24-hour baseline clock and stops silently learning new behavior after the baseline. Token-exchange events now populate their actual per-agent rate counter.
- Configuration reload now requires restart and applies no partial changes. The old implementation reported activation while modules, policies and middleware retained startup state. Existing explicit runtime enforcement APIs remain available.

## Verification and remaining work

The Go package suite passes with race detection, including the local dashboard and security regressions. Build, vet, staticcheck, gosec and reachable-vulnerability checks pass. Rust formatting, all-feature Clippy including tests, portable/PQC tests and dependency audit pass too. Windows portable tests include 200 unit tests plus one runtime integration test; all-feature linking requires the unavailable Npcap wpcap.lib locally. Linux CI supplies libpcap and must pass the full-feature tests before release. No live packet capture or production attack replay was performed.

Dependency checks report zero reachable Go vulnerabilities and no new Rust advisory failures. GO-2026-5932 concerns a required but unimported deprecated OpenPGP package, with no fixed release; it is not a reachable engine vulnerability. Five existing optional PQC/transitive maintenance exceptions remain visible: RUSTSEC-2024-0436, RUSTSEC-2026-0161, 0162, 0163 and 0166. Replacing that provider is a priority follow-up, not a hidden clean bill of health.

Next audit priorities are the unreviewed modules/fixtures, event-dedup fingerprints, normalization and high-cardinality packet state under load, a supported PQC provider migration, and verifier/runner integrations for SAML and tool admission. Optional capture's short-lived source/SSH trackers and broader detector state still need load measurements. Automated responses depend on trusted telemetry, configured policies, dry-run/approval choices and OS privileges. No universal prevention claim is justified.

## Upgrade prerequisites

The embedded bus data directory must be owned by the service account and support private permissions/ACLs. On a pre-existing Kubernetes PVC, fsGroup-only group write access may not permit tightening directory permissions; have the volume administrator set the mount's owner to the configured runAsUser before upgrading. Startup refuses a directory it cannot secure. No root init container or silent relocation of existing JetStream data is added. Preserve the existing data and credential file when restarting or backing up the instance. External collectors using an explicit --nats-url must supply the broker's credential via protected configuration/environment; default embedded collectors discover the credential automatically.
