# 1-SEC v0.4.33

## Local log collection in one executable

The main archive for your platform contains one 1-SEC executable. The embedded event broker, API, dashboard, collectors, and 16 existing modules run in that executable. Configure local log files under `collectors.sources` and start them with `1sec up`. The [collector setup guide](https://github.com/simpleending/1-sec/blob/v0.4.33/docs/connect-your-systems.md#connect-existing-logs-or-write-a-collector) includes a configuration example.

The collector CLI now starts the documented `auth` and `json` sources and reports missing files and invalid source settings. `1sec collect all` can connect a separately configured set of sources to a running engine. File tailers follow new records, and publishing failures appear in the logs. The optional GitHub Actions collector processes the runs returned by each poll in order and advances its cursor after successful publication.

## Startup, shutdown, and security fixes

- A busy API port or unusable TLS key pair now produces a startup error. Configure both TLS paths if you enable HTTPS.
- An authorized `1sec stop` uses the same cleanup path as Ctrl+C, including on Windows.
- Release lookup is opt-in through `1sec check --updates`.
- Enforcement settings and Token Vault validate the entire JSON body before changing settings or contacting a token provider. Requests must contain one complete JSON value within 64 KiB.
- The binaries use Go 1.26.11 and the patched event-broker compression dependency. [November 12 advisory and regression details](https://github.com/simpleending/1-sec/blob/v0.4.33/docs/security-updates/2026-11-12.md)

## Downloads and upgrade

Choose the archive for Linux, macOS, or Windows on AMD64 or ARM64. Verify it with the signed SHA-256 manifest and the release workflow identity. Each archive has a software bill of materials. The signed installer at [1-sec.dev/get](https://1-sec.dev/get) selects the archive for your platform.

Keep your existing configuration and private data directory. Stop the running instance, replace the executable, then restart and check readiness. The optional Rust sidecar is a separate download for deployments that already use it. Upgrade it alongside the main agent. Portable sidecar builds exclude native packet capture.

The release includes the earlier operator permission and durable auditing changes. The remote audit option still requires a separately deployed HTTPS receiver and private persistent storage. [Durable audit deployment guide](https://github.com/simpleending/1-sec/blob/v0.4.33/docs/security-updates/2026-11-05-v0.4.32.md)
