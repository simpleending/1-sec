Upgrade the Go tool and optional Rust sidecar together. Existing ownership, authenticated-bus and restart requirements still apply. Portable sidecars do not include packet capture. Saturation can evict useful history; capacity warnings expose that reduced coverage. Trusted telemetry and configured response policies remain necessary.

Regression evidence, measured normalization results, dependency decisions and validation limits are in [the follow-up implementation notes](2026-10-26-follow-up.md). This is a focused follow-up to the prior partial audit, not an exhaustive audit or a universal prevention guarantee.
