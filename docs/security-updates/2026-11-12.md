# November 12 weekly security update

The cycle covered November 5 at 01:48:48 UTC through November 12 at 01:48:48 UTC. Collection completed its configured queries for all four sources and retained 11 CISA KEV additions, 5,200 NVD publication records, 14,603 NVD modification records, and 258 GitHub-reviewed advisories. The feeds overlap and cover many products. The engineering review prioritized direct dependency matches and disclosures relevant to the engine. The local manifest retains the review backlog.

## HTTP requests must pass validation in full

The enforcement configuration and optional Token Vault exchange endpoints now validate one complete JSON value within their existing 64 KiB limit. A request that contains a second value, malformed trailing content, or more than 64 KiB is rejected before changing enforcement settings or contacting the token provider. These endpoints require an authorized API credential. Valid requests still accept JSON whitespace, including a request whose full body is exactly 64 KiB.

The enforcement regression reproduced a 200 response and a change out of dry-run mode for all three invalid request shapes. After the fix each returns 400 and leaves dry-run enabled. The Token Vault route rejects malformed bodies before token-field validation. Its positive control reaches the ordinary missing-fields response without calling an external service.

## Go and compression dependency patches

The Go minimum and Docker builder use Go 1.26.11. The CI and release workflows already use the Go version in `go.mod`. Both Go vulnerability scans flagged CVE-2026-97054 on 1.26.10. The upstream HTTP/1 regression passes with the patched toolchain. The advisory requires concurrent reads of an oversized request body and response-header writes. The inspected 1-SEC body handlers read synchronously, and the scanner's symbol matches do not establish that a request can trigger the race through these routes. The release also patches Go's compiler and linker tooling for builds involving malicious source or object files. [Go release notes](https://go.dev/doc/devel/release#go1.26.11) · [Go HTTP advisory](https://github.com/golang/go/issues/82563)

The OSV inventory flagged CVE-2026-116591 in the compression library pulled in by NATS. The engine links its `s2` and `flate` packages. The inspected build does not link the affected `fse`, `huff0` or `zstd` decoder paths. The module now requires upstream's first patched version, 1.20.2, and the embedded broker authentication and delivery-recovery regressions pass. [Maintainer advisory](https://github.com/klauspost/compress/security/advisories/GHSA-fpmh-frq8-7rj8)

## Website dependency checks

The website development audit traced seven moderate findings to one minimatch advisory. A scoped npm override upgrades the TypeScript ESLint parser's matcher to 11.0.1. The older matcher used by the other lint plugins stays on its supported version. The production website dependency audit was clear at collection. The refreshed React Server Components advisory, CVE-2026-126187, has a framework patch already present in the website's Next.js 16.4.1. The app configuration does not enable Cache Components, and the installed bundled serializer contains the patch. [Minimatch maintainer advisory](https://github.com/isaacs/minimatch/security/advisories/GHSA-g3hv-75wg-m249) · [Next.js security update](https://nextjs.org/blog/nextjs-security-update-october-14-2026)

## What the attack research means for integrations

- Check Point's November 5 ARTEX investigation documents attackers using agents to automate ordinary vulnerability discovery and exploitation. The engine can evaluate supplied HTTP and runtime events using its existing rules. Campaign attribution and the detection of activity outside the monitored paths require additional evidence. [Check Point investigation](https://research.checkpoint.com/2026/hacking-on-autopilot-inside-artex-cybercrime-campaigns/)
- Varonis's November 6 NotC2 proof of concept chains SQS, Lambda, SNS, and Bedrock using legitimate AWS APIs. The JSON log collector accepts individual CloudTrail records. To investigate this technique, operators need an AWS trail with appropriate data-event selectors and a feed that forwards the relevant records. IAM remains the enforcement point for restricting which service principals can invoke these APIs. [Varonis research](https://www.varonis.com/blog/notc2-ai-powered-c2-channel) · [AWS data-event documentation](https://docs.aws.amazon.com/awscloudtrail/latest/userguide/logging-data-events-with-cloudtrail.html)

The local workflow uses portable Rust tests on Windows. Linux CI covers full-feature Rust and sidecar integration. The Go fixes take effect in binaries and images built from the updated source. The v0.4.32 download was built before this cycle.
